**Virgil** - Indistinct's flagship. A persistent brain for Claude: talk naturally and it captures who's who and what's connected, writes it to a knowledge graph mid-conversation, and pulls the right context forward before the next ask. When facts change, the old record is superseded, never deleted - the brain keeps receipts. Ask it how it knows something and it can tell you: source, date, confidence. Built on Claude and on [gbrain](https://github.com/garrytan/gbrain), Garry Tan's open-source graph-memory engine, running in production with isolated tenants. Every artifact written back to a private repository - the record is the customer's, fully auditable, built to leave with them.
