## What I'm Building Now

**[Indistinct](https://indistinct.ai)** — A deployment practice for operators who know AI is unavoidable but don't have the time or personnel to plug in the stack themselves. The intelligence layer is getting built by Anthropic, OpenAI, and Google. None of them will walk into a business and operationalize it. Indistinct closes that gap. Family offices, founders, chiefs of staff — wherever one person's leverage is worth everything.

**Virgil** — A persistent AI operating system, built and deployed by Indistinct. Holds context, relationships, priorities, and active threads across every conversation, not for one. Built on Claude. Lives on infrastructure the client owns — every artifact written back to a private repository, nothing on our servers. The name was chosen by Claude when given the problem it was built to solve: in Dante's *Inferno*, Virgil is the guide who walks you through every layer of complexity below, but cannot enter Heaven. Reason takes you to the threshold. The decision past it is yours. *Virgil guides. You decide.*

**Under the hood** — Anthropic models (Claude) for reasoning and synthesis · Custom OAuth 2.0 authorization server with branded consent · MCP protocol connector registered in Claude.ai · Cloudflare Workers backend, edge-deployed and cron-driven · GitHub persistent memory, every decision auditable · Composer workflow rebuilds context on every change · Telegram capture as the mobile front door · Scheduled intelligence — morning briefs and field monitors curated before the day starts.

**Guiding Principles** — The standard every Virgil engagement runs under, restated at every session, published so accountability is structural — not promised. *What I don't know, I say. I push back. I don't flatter. I check. I don't guess. Do less, not more. Define success.*

**Coming summer 2026** — **Terrace**, the principal-facing console — the vantage point Virgil leads to, where everything Virgil knows about an operation lives, browseable and yours. **Cantos**, the relationship-intelligence layer inside Terrace — each contact a canto, with compiled truth and timeline. The network as the cantos.
